# Точки

Учебная игра на Python 3.11 и новее. Веб-интерфейс на русском, Flask API,
бот и симуляция. На ноутбуке подготовлено окружение `.venv` с Python 3.12.

## Запуск на этом ноутбуке

```sh
cd /Users/mivvari/project
.venv/bin/python app.py
```

Откройте http://127.0.0.1:8000. Остановить сервер: Ctrl+C.
Если порт занят: `PORT=8001 .venv/bin/python app.py`.

## Установка на другом компьютере

Убедитесь, что `python3 --version` показывает 3.11 или новее.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

## Как проверить

```sh
.venv/bin/python -m pytest -q
.venv/bin/python simulate.py --moves 60 --size 100
.venv/bin/python simulate.py --moves 30 --size none
```

Тесты проверяют диагональные кольца, разрывы, вложенные кольца, край поля,
большие и отрицательные координаты, корректность ходов, тактику бота,
формат API, ошибочные запросы и заполненное поле. На случайных позициях
результат сравнивается с обычной заливкой всего прямоугольника.

В браузере поставьте точку: красный бот должен ответить. Попробуйте отмену,
изменение масштаба, перетаскивание и перезагрузку страницы. Для проверки
захвата выберите игру с другом: синие ставят `(50,49)`, `(51,50)`,
`(50,51)`, `(49,50)`, красные между ними — `(50,50)`, `(55,55)`,
`(56,55)`. После четвёртого синего хода счёт будет **1 : 0**.

## Правила

- По умолчанию поле 100 × 100, координаты 0–99. `size=None` в Python
  (или `null` в JSON) включает бесконечное поле, включая отрицательные координаты.
- Игроки ходят по очереди на свободные пересечения. Синие начинают.
- Соседи — точки на один шаг по горизонтали, вертикали или диагонали.
- Кольцо из своих точек захватывает чужие точки внутри. Счёт равен числу
  захваченных точек противника. Край поля не считается забором.
- Ходы внутри окружённой области разрешены. Точки не удаляются и сохраняют
  свой цвет; захваченные точки тоже участвуют в цепочках. Это буквальная
  реализация предоставленных правил: отдельного правила отключения точек нет.
- На конечном поле партия завершается при заполнении. В остальных случаях
  можно закончить по договорённости, сравнив текущий счёт.

В интерфейсе есть бот, игра вдвоём на одном устройстве, поле 20 × 20,
бесконечный режим, сохранение в браузере, отмена и управление клавиатурой.
Стрелки выбирают точку, Enter ставит её, колесо меняет масштаб,
перетаскивание перемещает поле. В режиме бота отменяется пара ходов.

## Как ищется захват

Представьте свои точки забором, а свободное поле — водой. Берём
прямоугольник вокруг забора и расширяем на одну клетку. Из внешнего угла
вода идёт только вверх, вниз, влево и вправо. Через точки забора она не
проходит. Точки соперника, до которых вода не дошла, захвачены.

Связные заборы проверяем отдельно. Это даёт тот же результат, но не нужно
обходить огромное пустое пространство между удалёнными группами точек.
Позиции, заборы и посещённые клетки — множества пар; двумерного массива нет.

## Как выбирает ход бот

Бот рассматривает свободные места рядом с существующими точками,
оценивает соседей, проверяет возможность захвата и блокировку чужого кольца.
Он избегает ходов в уже окружённую соперником область.
Это понятный эвристический бот, а не поиск гарантированно лучшего хода.
`time_limit` — мягкий бюджет в секундах: текущая проверка завершается,
поэтому на больших позициях время может немного превысить лимит.
При `time_limit=0` бот выбирает ход только по соседям.
На полном поле возвращается `None`.

## API

Оба маршрута принимают POST с `Content-Type: application/json`.

```sh
curl -s http://127.0.0.1:8000/api/move \
  -H 'Content-Type: application/json' \
  -d '{"size":100,"me":[[50,50],[51,50]],"enemy":[[50,51]]}'

curl -s http://127.0.0.1:8000/api/score \
  -H 'Content-Type: application/json' \
  -d '{"size":100,"blue":[[1,1]],"red":[[2,2]]}'
```

`/api/move` возвращает `{"x": ..., "y": ...}`. Необязательное поле
`time_limit` принимает 0–2 секунды, по умолчанию 0.5. При полном поле —
HTTP 409 и `{"error":"…", "code":"board_full"}`.

`/api/score` возвращает `{"blue_captured":[],"red_captured":[]}`.
`blue_captured` — **синие, захваченные красными**. Поэтому счёт синего
игрока равен длине `red_captured`, а счёт красного — длине `blue_captured`.

Ошибочные данные возвращают HTTP 400 и `{"error":"…"}`. Лимит тела —
1 МБ (HTTP 413), до 10000 точек каждого цвета. `size` — любое положительное
целое число или `null`. API не хранит партии: клиент передаёт всю позицию.
Очередность ходов контролирует интерфейс или вызывающая программа.
