Точка за точкой.

Цель — захватить больше точек соперника.

  1. Ставьте точки по очереди на свободные пересечения сетки. Синие начинают.
  2. Соседние точки одного цвета соединяются по горизонтали, вертикали и диагонали.
  3. Замкните кольцо: чужие точки внутри него приносят вам очки.
  4. Внутри окружённой области ходить можно. Захваченные точки остаются на поле.

Диагональное кольцо тоже работает.
На примере синие получают 1 очко.
Край поля сам по себе не замыкает кольцо.
